# Контракт адаптера

Бот выполняет только GET к фиксированному `METRICS_URL`, добавляя `start`, `end`
и `platform`. Redirect запрещён. HTTPS обязателен, кроме localhost и точного
контейнерного имени `demo-source`. Токен передаётся заголовком Authorization.
Ответ — JSON до1МиБ, timeout8с. Не передавайте пароли/PII в данных отчёта.

Пример ответа для запроса `start=2026-01-01&end=2026-01-01&platform=all`:

```json
{
  "schemaVersion": 1,
  "period": { "start": "2026-01-01", "end": "2026-01-01", "timezone": "UTC" },
  "platform": "all",
  "updatedAt": "2026-01-01T12:00:00Z",
  "registrationsAll": 100,
  "registrationsByPlatform": [
    { "label": "Web", "count": 60 },
    { "label": "Приложение", "count": 40 }
  ],
  "totals": {
    "registrations": 100,
    "invoices": 18,
    "payers": 12,
    "jobsCompleted": 72,
    "jobsFailed": 2,
    "revenue": 3600,
    "currency": "RUB"
  },
  "funnel": [
    { "label": "Начали работу", "count": 86 },
    { "label": "Получили результат", "count": 72 }
  ],
  "providers": [
    { "id": "compute", "name": "Вычисления", "balance": { "amount": 18.02, "currency": "USD" }, "estimatedDays": 9 },
    { "id": "hosting", "name": "Хостинг", "balance": { "amount": 740, "currency": "RUB" }, "estimatedDays": 4 },
    { "id": "tasks", "name": "Задания", "balance": { "amount": 1200, "currency": "credits" }, "estimatedDays": null }
  ],
  "domains": [ { "name": "example.com", "paidTill": "2026-12-31T12:00:00Z" } ],
  "demo": true
}
```

Все значения здесь вымышлены. Для живого API ставьте фактический `updatedAt`,
возвращайте согласованный период/платформу и `demo: false`.
Не меняйте только дату старого снимка, чтобы обойти freshness-проверку.

## Определения

- Границы периода включительно, каждый день00:00–24:00 UTC.
- `registrationsAll` — все регистрации за период независимо от фильтра. Это
  знаменатель процентов во всех разделах, включая фильтр `web`/`app`.
- `registrationsByPlatform` — полное разбиение All по платформам за период.
- `totals.registrations`, воронка, счета, покупатели, задания и выручка относятся
  к запрошенной платформе. Покупатели — уникальные плательщики, не число оплат.
- Определения выручки/возвратов и шага воронки задаёт ваш сервис. Опишите их своим
  пользователям; бот не делает SQL и не меняет ваши финансовые записи.
- Текущие `providers` и `domains` не фильтруются по датам или платформе. Возвращайте
  только те аккаунты/домены, которыми владелец хочет делиться с одобренными зрителями.
- `balance: null` — остаток недоступен; `0` — настоящий ноль, отрицательное число — долг.
- `estimatedDays: null` — неизвестно, предупреждения о нехватке средств нет.
  Используйте прогноз провайдера либо явно описанный свой расчёт, не выдуманный тариф.
- `paidTill: null` — срок неизвестен, напоминания нет. Это оплаченный срок, не дата
  освобождения домена. После продления обязательно обновляйте значение.
- Цена продления и фактический кредитный баланс не выводятся из расходов. Если
  провайдер отдаёт только расход, не называйте его остатком.

Списки ограничены:6 платформ,12 шагов воронки,8 провайдеров,10 доменов. Подписи
до60 символов; имена доменов ASCII/punycode. Пустые списки `[]` разрешены.
Счётчики целые неотрицательные, деньги конечные, валюта ISO4217 либо `credits`
только для остатков. Неизвестные дополнительные поля отбрасываются.
Снимок старше `METRICS_MAX_AGE_SECONDS` отклоняется, часы допускают до60с вперёд.

## Запустить пример HTTP-источника

```sh
npm run demo-source
```

В другом терминале можно запросить
`http://localhost:8080/metrics?start=2026-01-01&end=2026-01-01&platform=all`.
Этот сервер выдаёт свежие синтетические данные, всегда `demo:true`, без авторизации.
Не размещайте его как настоящий источник финансовых данных.

Ваша реализация endpoint должна проверять read-only токен, вычислять агрегаты
из собственной системы и возвращать этот формат. Сам бот не требует менять
схему вашей базы данных или передавать ему доступ к ней.
